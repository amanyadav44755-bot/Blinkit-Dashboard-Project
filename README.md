# 🛒 Blinkit Sales Analysis Dashboard | Power BI
🚀 End-to-End Retail Sales Analytics Project (Power BI + Kaggle Dataset)
## 📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of Blinkit's sales performance, customer purchasing behavior, and outlet operations. The project transforms raw retail sales data into actionable business insights through interactive visualizations and KPI tracking.

The dashboard enables stakeholders to monitor sales trends, evaluate outlet performance, understand customer preferences, and make data-driven business decisions.
## 🧠 Problem Statement

Retail businesses struggle to understand sales performance and outlet efficiency.  
This dashboard solves this by providing a unified view of KPIs, trends, and category-wise insights.
---

## 🎯 Project Objectives

✔️ Analyze overall sales performance

✔️ Identify top-performing product categories

✔️ Evaluate outlet-wise sales and ratings

✔️ Understand customer purchasing patterns

✔️ Monitor key business KPIs through interactive visualizations

---

## 🛠️ Tools & Technologies Used

* 📊 Power BI
* ⚡ Power Query
* 🧮 DAX (Data Analysis Expressions)
* 📁 Microsoft Excel
* 📂 Kaggle Dataset

---

## 📂 Dataset Information

**Source:** Kaggle

**File Format:** Excel (.xlsx)

The dataset contains information related to:

* Product Categories
* Item Fat Content
* Sales Revenue
* Outlet Types
* Outlet Size
* Outlet Location
* Customer Ratings
* Outlet Establishment Year

---

## 📈 Key Performance Indicators (KPIs)

| KPI                 | Description                 |
| ------------------- | --------------------------- |
| 💰 Total Sales      | Total revenue generated     |
| 📦 Total Items Sold | Number of products sold     |
| 📊 Average Sales    | Average sales value         |
| ⭐ Average Rating    | Customer satisfaction score |
